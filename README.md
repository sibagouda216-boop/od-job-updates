## Preview locally
Open `index.html` in a browser. To preview through a local server, open a terminal in this folder and run:
`python -m http.server 8000`
Then open `http://localhost:8000`.

## Free publishing with GitHub Pages
1. Sign in/create a free account at https://github.com/.
2. Create a **public** repository named `od-job-updates`.
3. Upload the three files `index.html`, `style.css`, and `script.js` to the repository's top level (not inside another folder).
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then press **Save**.
7. Wait for GitHub Pages to finish building. Return to **Settings → Pages** and open the published URL. It usually resembles `https://YOUR-USERNAME.github.io/od-job-updates/`.

Alternative static hosting: https://app.netlify.com/drop. Follow the current upload/deployment prompts; if prompted, sign in.

## Before sharing publicly
- Sample job cards are illustrative categories and not confirmed live vacancies. Replace them with current, verified recruitment notices and correct official URLs.
- Replace “Add PDF link” buttons with real PDF links you have permission to share.
- Replace the YouTube video placeholder with actual video embeds if desired.
- Consider adding a privacy policy and terms/disclaimer page if you later collect user data or run ads.
- This is a static front-end. It has no admin dashboard or database; to update content, edit the HTML files and redeploy.

## Security note
Never share your account password or one-time verification codes. You can perform account sign-in and publishing steps yourself.
